# 使用者 review（來源：Notion「feedback>1」，2026-10-21）

## 使用者的意圖（我讀到的）

1. **標註放左上角。** 物體的類別、信心、世界座標、距離，之後只留在畫面左上角的清單，不要貼在物體旁邊。清單的數字要隨手臂移動即時變動（因為是影片在持續算距離與世界座標）。測試階段目前的樣子可以接受。
2. **查原因。** `outputs/lab/live/run_20261020_204052/frames/f00016.jpg` 開始有些物體沒被分割到，為什麼？
3. **拿掉原本的紅色方塊 `object`。** 它和隨機生成的積木性質不同，但畫面上看起來一樣，會讓人搞混。一開始就把它移走，之後只用隨機生成的積木。
4. **「還不穩」的部分留給之後的 agent。** 這次只要一個非常初步的測試，看功能能不能用。我測試期間沒有人在操作 Isaac Sim（所以先前「別人在驅動手臂」不是人為，原因要自己查）。
5. **要能重現。** 使用者用 `detect_pick("sphere")` 看到的和以前一模一樣（因為它跑的是舊的 `demo_start.py`）。要做一個 **`demo_start2.py`**，反映這次的改變：
   - 只要 `layout()` 與 `detect_pick()` 兩個功能。
   - (1) 不再用兩次拍照確認位置，改用 D455 錄影，隨時辨識物體位置與距離。
   - (2) 移動過程順暢、不停頓。
   - (3) 抓取不停格；放置不要丟下（放在籃面上）。
6. 另外寫 `lab/README-lab.md`（照 README.md 的格式），讓使用者知道怎麼操作。全程用 git。
